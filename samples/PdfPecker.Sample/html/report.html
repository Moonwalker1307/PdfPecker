PdfPecker feature tour

This document exercises the HTML and CSS features that PdfPecker supports. It is rendered without a browser, straight from HTML to PDF.

1. Text and inline formatting

Inline styles: bold, italic, bold italic, underlined, struck, highlighted, small, big, H2O and E = mc2, coloured and monospace text. Links work too: an external link and an internal link. Special characters: © ® ™ € £ — “quotes” … café naïve Ångström.
